About Me

Hi! My name is Amirkhan Assetov, and this is my personal website for DS4200. I am learning how to communicate information through websites and data visualizations. This site brings those ideas together in a small project. The home page introduces me, and the second page shows a simple example of how a chart can help explain data. The photo on this page is a picture of me outdoors on a sunny day.

For this assignment, I wanted to keep the website easy to read and easy to use. The navigation at the top connects both pages, so visitors can move between the introduction and the data example. I used basic HTML to organize the headings, paragraphs, images, and links. A separate CSS file controls the colors, spacing, and fonts. Keeping the content and styling in separate files makes the code easier to follow when I return to it later.

My work in DS4200 gives me a way to practice turning information into something people can understand visually. A useful chart needs more than bars or colors. It also needs a clear title, labels, and an explanation of what the values represent. On the data exploration page, I use a small sample dataset to demonstrate those choices. You can visit that page to see the visualization, read about the example, and learn how it connects to the website tutorial.
