Exploring Data with Simple Charts

This page continues my introduction by showing an example of the visualization work I am practicing in DS4200. A bar chart is a useful starting point because its structure is easy to understand. Each bar represents one category, and the height represents a number. When the bars share the same baseline, a reader can compare the values without having to read every number in a table.

The image below comes from the Altair chart in my original website tutorial. It shows nine letter categories with different values. This is a practice dataset, so the letters do not stand for real people or events. I included the image as an example of a chart saved as an SVG file. An SVG image stays clear when it is resized, which makes it useful for displaying a chart on different screen sizes.

The D3 visualization below uses the same sample values. Category D has the largest value, while category G has the smallest. The horizontal axis identifies the categories, and the vertical axis shows the value. The numbers above the bars make exact comparisons easier. This example shows how a saved chart image and a chart created with JavaScript can communicate the same information in two different ways.

Things I check when making a chart

  • Give the chart a clear title.
  • Label the categories and values.
  • Start the bar chart's value axis at zero.
  • Explain where the data comes from.
